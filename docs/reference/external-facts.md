# External facts registry

> Reference (lookup). Perishable facts (crate versions, external tool behavior, source URLs) that the
> Rust binding relies on. Per docs-design `08-tracking-and-revalidation.md`, each row carries a
> **Last checked** and **Revalidate by** date so it can be re-verified on a cadence. When you
> revalidate, update both dates and any changed fact, and note version bumps back to
> `docs-n-notes/tech/languages/rust/cli-spec`.

## Notes

- Version numbers above are advisory. The build's actual versions come from `cargo add` and are pinned
  exactly in `Cargo.lock` (ADR-0012). Prose in the spec names crates, not versions.
- A `cog research-shelf record` entry is an optional additional home for these facts; this file is the
  durable in-repo registry.
